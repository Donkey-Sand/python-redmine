## 10. 避免分母重复统计

如果把同一个分母复制到每条错误记录上，再在QuickSight中使用`SUM`，分母会被重复累加。

例如：

| 月份 | Error Code | 分子 |  分母 |
| -- | ---------- | -: | --: |
| 3月 | E001       | 10 | 100 |
| 3月 | E002       |  5 | 100 |

如果直接`SUM(分母)`，会得到200，而正确分母可能仍然是100。

必须考虑：

* [ ] 使用`MAX(分母)`是否合适
* [ ] 使用`MIN(分母)`是否合适
* [ ] 使用去重后的分母
* [ ] 分母单独建立数据集
* [ ] 在View中控制数据粒度
* [ ] 使用QuickSight的Level-Aware Calculation

## 13. 不要急着把所有数据强行合并到一张表

错误数据和NW连接数据的日期含义不同：

* 错误数据：错误发生日期
* NW数据：设备连接日期

因此需要注意：

* [ ] 不能简单按照日期直接JOIN
* [ ] JOIN前先统一到月份是否可行
* [ ] JOIN后是否造成一对多重复
* [ ] 没有错误但存在连接设备的月份是否保留
* [ ] 没有新增连接但存在错误的月份是否保留

可能需要单独的月份基准表（Calendar／Month Master）确保所有月份都能显示。
